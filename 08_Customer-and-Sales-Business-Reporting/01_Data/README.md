# 📁 Data

This folder contains information about the dataset used in this project.

The original dataset was collected during my internship and includes customer transactions, product sales, treatment history, and business reporting data from XXX Company covering the period from **2021 to 2025**.

Due to the confidential nature of the data, the original dataset is **not included** in this repository.

---

# 📊 Dataset Overview

The dataset was used to generate business reports related to:

- Customer Growth
- Customer Retention
- Cohort Analysis
- Product Sales Performance
- Top Customer Analysis
- Product Performance Evaluation

The reports were developed using Microsoft Excel to support business monitoring and decision-making.

---

# 🔒 Data Confidentiality

The original dataset contains sensitive company and customer information, including transaction records and customer identities.

To comply with data privacy and confidentiality requirements:

- Original datasets are not shared.
- Customer identities have been removed from all report previews.
- Only project documentation and report screenshots are available in this repository.

---

# 📈 Data Source

- Company Internal Transaction Database
- Customer Purchase Records
- Product & Treatment Sales Data

Although the original dataset is not publicly available, this repository demonstrates the complete business reporting workflow, analytical approach, and reporting outputs developed using Microsoft Excel.
