# 📁 Data

This folder contains information about the dataset used in the SQL Data Cleaning project.

The dataset consists of global layoff records collected from publicly available sources. It contains information related to company layoffs across various industries, countries, and funding stages.

The raw dataset serves as the foundation for practicing SQL data cleaning techniques before conducting further data analysis.

---

# 📊 Dataset Overview

The dataset includes information such as:

- Company Name
- Industry
- Country
- Location
- Total Employees Laid Off
- Percentage Laid Off
- Date
- Company Stage
- Funds Raised

The dataset contains common real-world data quality issues that require cleaning before analysis.

---

# 🧹 Data Quality Issues

The raw dataset includes several inconsistencies, including:

- Duplicate records
- Missing values
- Inconsistent text formatting
- Extra whitespace
- Blank values
- Inconsistent date formats
- NULL values
- Redundant records

These issues were addressed using SQL before the dataset became suitable for analysis.

---

# 📈 Data Source

The dataset is based on publicly available layoff records commonly used for SQL learning and portfolio projects.

---

# 🚀 Project Purpose

The purpose of this dataset is to demonstrate an end-to-end SQL data cleaning workflow.

The project focuses on transforming raw, unstructured data into a clean and reliable dataset that is ready for reporting, visualization, and further business analysis.
