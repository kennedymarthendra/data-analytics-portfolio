# 📊 Power BI Dashboard

This folder contains the interactive Power BI dashboard developed to analyze Blinkit retail sales performance.

## File Included

| File | Description |
|------|-------------|
| **Blinkit Sales Analysis Dashboard.pbix** | Interactive Power BI dashboard for monitoring sales performance, outlet comparison, product category analysis, and operational KPIs. |

## Dashboard Features

### KPI Cards

- Total Sales
- Average Sales
- Number of Items Sold
- Average Customer Rating

### Interactive Visualizations

- Outlet Establishment Trend
- Sales by Fat Content
- Sales by Item Type
- Fat Content by Outlet Tier
- Outlet Size Distribution
- Outlet Location Performance
- Outlet Type Performance Table

### Interactive Filters

- Outlet Location Type
- Outlet Size
- Item Type

## Data Preparation

Power Query was used to clean, transform, and prepare the dataset before building the Power BI data model.

## DAX Measures

Several DAX measures were created to calculate key business metrics, including:

- Total Sales
- Average Sales
- Number of Items Sold
- Average Rating
- Sales by Outlet Type
- Sales by Outlet Size
- Sales by Item Category
- Item Visibility Metrics

These calculations enable interactive retail sales analysis and support data-driven operational decision-making.
