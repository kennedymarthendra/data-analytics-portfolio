## Dashboard Highlights

The dashboard provides a comprehensive overview of retail business performance through:

- Total Sales KPI
- Average Sales KPI
- Number of Items Sold
- Average Customer Rating
- Outlet Establishment Trend
- Sales by Fat Content
- Item Type Performance
- Outlet Size Distribution
- Outlet Location Comparison
- Outlet Type Performance Table
- Interactive Filters for Outlet Location, Outlet Size, and Item Type

The dashboard enables stakeholders to monitor outlet performance, evaluate product category contributions, compare outlet characteristics, and identify business opportunities through interactive visual analytics.
