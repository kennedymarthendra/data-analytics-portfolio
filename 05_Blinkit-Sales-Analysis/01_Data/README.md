# 📁 Dataset

This folder contains the raw dataset used to build the Blinkit Sales Analysis dashboard.

## Dataset Description

The dataset contains Blinkit grocery sales transactions, product information, outlet characteristics, customer ratings, and item visibility metrics. It serves as the primary data source for data preparation, KPI calculation, and interactive dashboard development in Power BI.

## File Included

| File | Description |
|------|-------------|
| **blinkit_sales_dataset.xlsx** | Raw Blinkit retail sales dataset used throughout the business analysis and dashboard development. |

## Dataset Features

The dataset contains information such as:

- Outlet Establishment Year
- Outlet Location Type
- Outlet Size
- Outlet Type
- Item Identifier
- Item Type
- Fat Content
- Item Visibility
- Item Weight
- Sales
- Customer Rating

## Purpose

This dataset was used to:

- Monitor overall sales performance
- Analyze outlet performance
- Compare outlet sizes and outlet locations
- Evaluate product category performance
- Analyze fat content contribution
- Build an interactive Power BI dashboard
