# 📁 Dataset

This folder contains the raw dataset used to build the Amazon Product Sales Analysis dashboard.

## Dataset Description

The dataset contains Amazon product sales information, including product categories, sales transactions, customer reviews, and product performance metrics. It serves as the primary data source for Power BI modeling and business performance analysis.

## File Included

| File | Description |
|------|-------------|
| **amazon_sales_dataset.xlsx** | Raw Amazon product sales dataset used throughout the dashboard development and business analysis. |

## Dataset Features

The dataset contains information such as:

- Product Category
- Product Name
- Sales Amount
- Quantity Sold
- Customer Reviews
- Order Date
- Quarter
- Month
- Week
- Year-to-Date (YTD) Sales
- Quarter-to-Date (QTD) Sales

## Purpose

This dataset was used to:

- Analyze overall sales performance
- Monitor YTD and QTD sales
- Evaluate product category contribution
- Identify top-selling products
- Analyze customer review trends
- Build an interactive Power BI dashboard
