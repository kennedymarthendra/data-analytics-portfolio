# 📊 Power BI Dashboard

This folder contains the interactive Power BI dashboard developed to analyze Amazon product sales performance.

## File Included

| File | Description |
|------|-------------|
| **Amazon Sales Analysis Dashboard.pbix** | Interactive Power BI dashboard for monitoring sales performance, product categories, customer reviews, and product rankings. |

## Dashboard Features

### KPI Cards

- YTD Sales
- QTD Sales
- YTD Products Sold
- YTD Reviews

### Interactive Visualizations

- Monthly Sales Trend
- Weekly Sales Trend
- Sales by Product Category
- Top 5 Products by YTD Sales
- Top 5 Products by Customer Reviews

### Interactive Filters

- Product Category
- Quarter (QTR)

## Data Preparation

Power Query was used to clean, transform, and prepare the dataset before creating the Power BI data model.

## DAX Measures

Several DAX measures were created to calculate key business metrics, including:

- Year-to-Date (YTD) Sales
- Quarter-to-Date (QTD) Sales
- YTD Products Sold
- YTD Customer Reviews
- Product Category Contribution (%)
- Top Product Rankings

These calculations enable interactive product performance analysis and support business decision-making through dynamic reporting.
