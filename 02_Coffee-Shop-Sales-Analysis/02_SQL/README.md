# 💾 SQL Analysis

This folder contains the SQL script used to explore coffee shop sales data and answer key business questions before building the Power BI dashboard.

## File Included

| File | Description |
|------|-------------|
| **Coffee Shop Sales Project.sql** | SQL queries used for data exploration, business analysis, and KPI generation. |

## SQL Techniques

The SQL analysis applies various analytical techniques, including:

- Data Exploration
- Aggregate Functions
- GROUP BY
- ORDER BY
- CASE WHEN
- Date Functions
- Time-based Analysis
- Sales Aggregation
- Ranking and Sorting
- Filtering and Conditional Queries

## Business Questions Answered

The SQL analysis helps answer questions such as:

- What are the total sales, total orders, and total quantity sold?
- Which product categories generate the highest revenue?
- Which individual products perform the best?
- Which store locations contribute the highest sales?
- How do weekday and weekend sales compare?
- Which hours of the day experience the highest sales activity?
- What are the daily sales trends during the reporting period?
