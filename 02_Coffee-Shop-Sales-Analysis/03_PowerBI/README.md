# 📊 Power BI Dashboard

This folder contains the interactive Power BI dashboard developed to analyze coffee shop sales performance.

## File Included

| File | Description |
|------|-------------|
| **Coffee Shop Sales Analysis Dashboard.pbix** | Interactive Power BI dashboard featuring KPIs, sales trends, store performance, and customer purchasing insights. |

## Dashboard Features

### KPI Cards

- Total Sales
- Total Orders
- Total Quantity Sold

### Interactive Visualizations

- Daily Sales Trend
- Sales by Product Category
- Top 10 Products
- Weekday vs Weekend Sales
- Sales by Store Location
- Sales Heatmap by Day & Hour

### Interactive Filters

- Month Selection
- Calendar View

## Data Preparation

Power Query was used to clean, transform, and prepare the transactional dataset before creating the Power BI data model.

## DAX Measures

Several DAX measures were created to calculate important business KPIs, including:

- Total Sales
- Total Orders
- Total Quantity Sold
- Previous Month Sales
- Sales Growth
- Month-over-Month Performance

These calculations enable dynamic reporting and interactive business analysis.
