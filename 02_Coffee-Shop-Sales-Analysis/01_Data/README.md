# 📁 Dataset

This folder contains the raw transactional dataset used to build the Coffee Shop Sales Analysis project.

## Dataset Description

The dataset records daily coffee shop sales transactions, including order information, product details, store locations, quantities sold, and sales values. It serves as the primary data source for SQL exploration, Power BI modeling, and business performance analysis.

## File Included

| File | Description |
|------|-------------|
| **coffee_shop_sales_dataset.xlsx** | Raw sales transaction dataset used throughout the analysis and dashboard development. |

## Dataset Features

The dataset contains information including:

- Transaction ID
- Transaction Date
- Transaction Time
- Store Location
- Product Category
- Product Type
- Product Name
- Quantity Sold
- Unit Price
- Total Sales

## Purpose

This dataset was used to:

- Analyze daily sales performance
- Compare weekday and weekend sales
- Identify best-selling products
- Evaluate store performance
- Discover hourly sales patterns
- Build interactive Power BI dashboards
