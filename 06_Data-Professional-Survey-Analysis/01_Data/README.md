# 📁 Dataset

This folder contains the raw survey dataset used to build the Data Professional Survey Analysis dashboard.

## Dataset Description

The dataset consists of survey responses collected from data professionals across multiple countries. It includes demographic information, career roles, programming language preferences, salary levels, work-life balance satisfaction, and perceptions about entering the data industry.

## File Included

| File | Description |
|------|-------------|
| **data_professional_survey_dataset.xlsx** | Raw survey dataset used for data preparation, exploratory analysis, and Power BI dashboard development. |

## Dataset Features

The dataset contains information such as:

- Country of Residence
- Job Title
- Age
- Annual Salary
- Favorite Programming Language
- Work-Life Balance Satisfaction
- Salary Satisfaction
- Difficulty Breaking into Data
- Survey Respondent Information

## Purpose

This dataset was used to:

- Analyze salary distribution across data professions
- Compare programming language preferences
- Evaluate work-life balance satisfaction
- Measure salary satisfaction
- Explore career entry challenges
- Build an interactive Power BI dashboard
