## Dashboard Highlights

The dashboard provides a comprehensive overview of survey findings through:

- Total Survey Respondents
- Average Respondent Age
- Survey Respondents by Country
- Average Salary by Job Title
- Favorite Programming Languages
- Difficulty Breaking into Data
- Work-Life Balance Satisfaction
- Salary Satisfaction

The dashboard enables users to explore demographic trends, compare salaries across data-related roles, understand programming language preferences, and evaluate overall career satisfaction within the data profession through interactive visual analytics.
