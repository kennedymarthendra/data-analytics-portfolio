# 📊 Power BI Dashboard

This folder contains the interactive Power BI dashboard developed to analyze survey responses from data professionals.

## File Included

| File | Description |
|------|-------------|
| **Data Professional Survey Analysis Dashboard.pbix** | Interactive Power BI dashboard for analyzing demographic profiles, salary trends, programming language preferences, and career satisfaction among data professionals. |

## Dashboard Features

### KPI Cards

- Total Survey Respondents
- Average Age of Respondents

### Interactive Visualizations

- Survey Respondents by Country
- Average Salary by Job Title
- Favorite Programming Language
- Difficulty Breaking into Data
- Work-Life Balance Satisfaction
- Salary Satisfaction

### Dashboard Insights

The dashboard enables users to:

- Compare average salaries across different data-related roles.
- Identify the most popular programming languages among survey respondents.
- Explore the geographic distribution of data professionals.
- Analyze perceptions of difficulty when entering the data industry.
- Evaluate work-life balance and salary satisfaction.

## Data Preparation

Power Query was used to clean, transform, and prepare the survey dataset before building the Power BI data model.

## DAX Measures

Several DAX measures were created to calculate key survey metrics, including:

- Total Survey Respondents
- Average Age
- Average Salary by Job Title
- Work-Life Balance Score
- Salary Satisfaction Score
- Programming Language Distribution
- Difficulty Level Distribution

These calculations support interactive demographic analysis and provide meaningful insights into career trends within the data profession.
