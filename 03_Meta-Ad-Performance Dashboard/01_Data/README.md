# 📁 Dataset

This folder contains the raw datasets used to build the Meta Ad Performance Analysis dashboard.

## Dataset Description

The project combines multiple datasets representing advertising campaigns, user demographics, ad events, and campaign information. These datasets were integrated to analyze marketing performance across Meta advertising platforms.

## Files Included

| File | Description |
|------|-------------|
| **ad_events.xlsx** | User interaction records including impressions, clicks, engagements, and purchases. |
| **ads.xlsx** | Advertisement information including ad type and campaign relationships. |
| **campaigns.xlsx** | Campaign-level details such as campaign name, budget, platform, and targeting information. |
| **users.xlsx** | User demographic information including gender, age group, country, and interests. |

## Dataset Features

The combined dataset contains information such as:

- Campaign Information
- Advertising Platform
- Ad Type
- User Demographics
- Gender
- Age
- Country
- Target Interest
- Impressions
- Clicks
- Shares
- Comments
- Purchases
- Budget Allocation
- Campaign Dates

## Purpose

These datasets were integrated to:

- Evaluate campaign performance
- Analyze audience engagement
- Compare Facebook and Instagram campaigns
- Measure advertising effectiveness
- Build interactive marketing dashboards
