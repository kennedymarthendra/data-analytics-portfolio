# 🖼️ Dashboard Images

This folder contains screenshots of the Meta Ad Performance Dashboard used throughout the project documentation.

## Images Included

| Image | Description |
|------|-------------|
| **facebook-dashboard.png** | Dashboard presenting Facebook advertising performance, campaign KPIs, audience demographics, engagement analysis, and campaign effectiveness. |

## Dashboard Highlights

### Facebook Dashboard

The Facebook dashboard provides insights into:

- Campaign performance KPIs
- Audience demographics
- Geographic engagement distribution
- Weekly engagement trends
- Hourly engagement patterns
- Advertisement type performance
- Campaign filtering by interest and campaign

### Instagram Dashboard

The Instagram dashboard enables comparison of:

- Campaign performance
- Engagement behavior
- Audience demographics
- Geographic reach
- Weekly and hourly engagement trends
- Advertisement effectiveness
- Marketing campaign performance

These screenshots provide a complete overview of the interactive dashboard without requiring Power BI Desktop.
