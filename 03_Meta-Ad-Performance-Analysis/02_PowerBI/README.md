# 📊 Power BI Dashboard

This folder contains the interactive Power BI dashboard developed to analyze Meta advertising performance across Facebook and Instagram campaigns.

## File Included

| File | Description |
|------|-------------|
| **Meta Ad Performance Dashboard.pbix** | Interactive Power BI dashboard for monitoring digital marketing KPIs, audience engagement, campaign effectiveness, and platform comparison. |

## Dashboard Features

### KPI Cards

- Impressions
- Clicks
- Shares
- Comments
- Purchases
- Engagements
- CTR (Click Through Rate)
- Engagement Rate
- Conversion Rate
- Purchase Rate
- Total Budget
- Average Budget per Campaign

### Interactive Visualizations

- Engagement by Gender
- Engagement by Age
- Engagement by Country
- Weekly Engagement Trend
- Hourly Engagement Trend
- Performance by Advertisement Type
- Monthly Calendar Analysis

### Interactive Filters

- Dynamic KPI Selector
- Campaign Name
- Target Interest
- Facebook / Instagram Platform Switch

## Data Preparation

Power Query was used to clean, transform, and combine multiple datasets before creating the Power BI data model.

## DAX Measures

Several DAX measures were created to calculate important digital marketing KPIs, including:

- Total Impressions
- Total Clicks
- Total Purchases
- Total Engagements
- CTR
- Engagement Rate
- Conversion Rate
- Purchase Rate
- Dynamic KPI Selection

These calculations enable flexible campaign performance monitoring and interactive business analysis.
