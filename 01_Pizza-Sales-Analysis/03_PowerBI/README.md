# 📊 Power BI Dashboard

This folder contains the interactive Power BI dashboard developed for Pizza Sales Analysis.

## File Included

| File | Description |
|------|-------------|
| **Pizza Sales Analysis Dashboard.pbix** | Interactive Power BI dashboard that visualizes pizza sales performance using KPIs, charts, filters, and DAX measures. |

## Dashboard Features

### KPI Cards

- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas per Order

### Interactive Visualizations

- Daily Sales Trend
- Monthly Sales Trend
- Sales by Pizza Category
- Sales by Pizza Size
- Top & Bottom Performing Products

### Interactive Filters

- Pizza Category
- Date Range

## Data Preparation

Power Query was used to import and prepare the dataset before creating the Power BI data model.

## DAX Measures

The dashboard includes several DAX measures to calculate business KPIs, including:

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Average Pizzas per Order

These measures enable dynamic filtering and interactive business analysis.
