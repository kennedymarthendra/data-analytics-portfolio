# 📁 Dataset

This folder contains the raw dataset used to develop the Pizza Sales Analysis Dashboard.

## Dataset Description

The dataset consists of historical pizza sales transactions collected during the reporting period. It includes order details, pizza categories, pizza sizes, pricing information, quantities sold, and transaction dates used to perform business analysis and dashboard development.

## File Included

| File | Description |
|------|-------------|
| **pizza_sales_dataset.xlsx** | Raw transactional sales dataset used for SQL analysis, Power BI data modeling, DAX calculations, and dashboard visualization. |

## Dataset Features

The dataset contains information such as:

- Order ID
- Order Date
- Pizza Name
- Pizza Category
- Pizza Size
- Quantity Sold
- Unit Price
- Total Price

The dataset serves as the primary data source for both SQL analysis and Power BI reporting.
