# 💾 SQL Analysis

This folder contains the SQL script used to explore and analyze pizza sales data before building the Power BI dashboard.

## File Included

| File | Description |
|------|-------------|
| **Pizza Sales Analysis.sql** | SQL queries used to answer business questions and generate analytical insights from the transactional sales dataset. |

## SQL Techniques

The SQL analysis utilizes several techniques, including:

- Data Exploration
- Aggregate Functions
- GROUP BY
- ORDER BY
- CASE WHEN
- Date Functions
- Common Business Aggregations
- Ranking and Sorting
- Filtering and Conditional Queries

## Business Questions Answered

The SQL queries help answer important business questions such as:

- What is the total revenue?
- What is the average order value?
- How many pizzas were sold?
- Which pizza categories generate the highest sales?
- Which pizza sizes contribute the most revenue?
- Which days and months record the highest number of orders?
- Which products are the best and worst performers?
